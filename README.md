# Pitching Mechanics Feedback Report (portfolio demo)

Interactive, single-file HTML report built for pitching coaches to review each pitcher's mechanics against similar peers and against his own history.

**All data in this demo is simulated** (36 fictional pitchers, 94,133 pitches). The original tool runs on confidential club data and is in Japanese; this is an English rebuild for portfolio use.

- Modules: mechanics summary with auto-generated feedback, metric detail, monthly and per-outing trends, pitch-type consistency, velocity drivers, command, 17-zone results
- Live demo: https://liupuzhenz13.github.io/pitching-report/
- Or download `index.html` and open it in any web browser. No installation or login required.
